# Preserve Photo identity when replacing an Image Asset

When an Admin replaces an Image Asset, the existing Photo Entry remains in place so its likes, comments, metadata, and gallery identity remain attached. The new Image Asset must be uploaded and published before the Photo Entry is relinked and published; if that process fails, the existing published Photo remains live and the incomplete replacement is cleaned up. After a successful replacement, the old Image Asset is unpublished and removed automatically; manual Photo deletion remains a separate future feature.
